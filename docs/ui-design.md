# UI 명세서

## 1. 간단 설명

- 반응형 웹 페이지
 
## 2. 기술 스택

- HTML, CSS, JavaScript

## 3. UI 구현

### 로고
- 왼쪽 위 가장 구석에 로고를 위한 공간 마련

### 메뉴
- 공통 (로고 오른쪽에 [+] 버튼에서 사진 업로드 가능, 앨범/챗봇 VIEW 사이에 스위칭할 수 있는 버튼 두 개를 왼쪽 가장자리에 배치) (사이드바는 따로 제작하지 않는다)

#### 앨범 VIEW 
(데이터베이스에 있는 사진 보여주는 '사진 앨범')
- 앨범 사진 VIEW (사진을 날짜별로 나열)
    - Sort by (과거~현재, 현재~과거)
    - X photos per row (1, 3, 5, 7, 10)
- 앨범 추억 VIEW (이벤트별로 사진 묶어 놓음)

#### 챗봇 VIEW 
(주 기능, 유저 쿼리에 따른 챗봇 사진 반환)

### 디자인
- 일단은 심플하게 가자. 흰색 및 하늘색 계열의 심플한 디자인, 다크 모드 없음
- 기능이 많지 않으니 현존하는 기능에 집중, 기능만큼이나 전반적으로 심플한 디자인

## 4. UI 세부 사항

### PC 인터페이스

#### 앨범VIEW
- 앨범 VIEW에서도 채팅창과 상호작용 가능
- 앨범 VIEW에서 검색창에 프롬프트 입력하면 채팅창으로 변함, 채팅창이 아래쪽으로 확장되어 챗봇의 출력 볼 수 있음 (채팅창은 전체 UI 세로 크기를 대부분 차지하는 큰 박스, 스크롤 가능)

#### 챗봇VIEW
- 채팅 화면 일부 공간 할당해서 ‘사진 갤러리’ VIEW 제작
    - 챗봇이 반환하는 사진 크게 보여 줌
    - 모든 대답(일반 에이전트의 일상 대화 빼고)은 사진을 동반하고, 사진을 보는 것이 중요하니까 사진을 크게 보여줌
    - 평소에는 숨어 있다가, 사용자가 첫 쿼리 보내고 챗봇이 대답으로 사진 반환할 때 확장
    - 가로로 길게 (챗봇UI 가로 꽉 채워서), 세로로는 전체 화면의 1/2
    - 사이드스크롤로 사진들 탐색 가능 (스냅 스크롤 아님)
    - 최대 10개의 사진 (이거는 바뀔 수 있음)
    - 사진 호버링하면 캡션(키워드 목록) 표시
    - 개별 사진 클릭하면 화면 가득 사진을 띄워주는 라이트박스 기능 
- or 채팅 화면을 세로로 반 갈라 채팅 왼쪽, '사진 갤러리' VIEW를 오른쪽? (둘 다 해보기)
- 채팅창은 가장 일반적인 디자인으로 시작 
    - 오른쪽에 사용자의 질문이 오도록
    - 왼쪽에 챗봇의 대답이 오도록
    
- 사진 분석 및 RAG 검색이 오래 걸릴 수 있으므로, 답변을 생성 중일 때 '생성 중...' 애니메이션을 챗봇 답변 영역에 표시


### 모바일 인터페이스

- Hamburger Menu처럼 버튼 눌러야 메뉴 나오지 않고, (모바일 앱이나 웹사이트처럼) 최하단에 내비게이션 메뉴 (Bottom Navigation Bar)로 앨범 VIEW / 채팅 VIEW 전환 가능
- 아이폰의 홈 바 등과 내비게이션 바가 겹치지 않도록 safe area 여백 설정 (ex. pb-[safe-area])

#### 앨범 VIEW 
- 검색창 위쪽 길게 
- 검색창에 요청 입력하면 챗봇 VIEW로 바로 넘어감

#### 챗봇 VIEW
- 사용자 터치 위치를 고려해, 채팅 화면을 가로로 1:2 위치에 갈라 '사진 갤러리' VIEW는 화면 위쪽에 위치 (세로 1/3), 화면 아래쪽은 채팅 영역 (세로 2/3)
- 키보드가 올라올 공간 또한 고려, 키보드가 올라오면 일시적으로 '사진 갤러리' VIEW가 위로 밀려들어감

## 6. 추가 UI 디자인 결정 사항 (Floating Warm Card)

프론트엔드 정교화 과정에서 **Apple Photos**의 부드럽고 따뜻한 감성과 현대적인 투명도(Glassmorphism)를 차용한 디자인 시스템을 적용했습니다.

### 6.1 네비게이션 (Sidebar & BottomNav)
- **알약 형태의 플로팅 디자인**: 화면 모서리에 딱 붙는 일반적인 각진 패널 형태를 벗어나, 마진을 둔 둥근 알약(Pill) 모양의 떠 있는 듯한(Floating) 카드로 제작하여 시각적인 답답함을 해소하고 세련됨을 강조했습니다.
- **얕은 크림색 & 투명도 (Warm Glassmorphism)**: 메인 배경색인 얕은 크림색(`bg-[#FDFBF7]`)과 잘 블렌딩되도록 네비게이션 바에 `backdrop-blur-xl`과 화이트 반투명(`bg-white/70`, `bg-white/80`)을 적용해 깊이감을 주었습니다.
- **아이콘 기반의 미니멀리즘**: 데스크톱 사이드바는 텍스트를 제거하고 좁은 폭(`w-20`)에 직관적인 아이콘만 배치하여 사진(콘텐츠)에 온전히 집중할 수 있도록 했습니다. 텍스트 라벨은 마우스 오버(Hover) 시 나타나는 Tooltip으로 대체했습니다.
- **로고 디자인 간소화**: 사이드바 상단의 카메라 로고는 배경과 그림자를 제거하여 뷰 전환 시 깔끔한 "Home" 버튼 역할을 하도록 퓨어하고 시크하게 구성했습니다.

### 6.2 업로드 버튼 상호작용
- **수직 확장 애니메이션**: 공간 효율을 극대화하고 동적인 재미를 주기 위해, 기본 상태에서는 아이콘(`+`)만 보이다가 마우스를 올리면 버튼이 위쪽으로 부드럽게 늘어나며 숨겨져 있던 `UPLOAD` 텍스트(자간이 넓지 않은 깔끔한 폰트)를 보여주는 방식으로 설계했습니다.

### 6.3 앨범 뷰 제어 (Album View Controls)
- **정렬 (Sort by)**: 상단 헤더에 `Oldest / Newest` 토글 버튼을 추가하여 시간순/역순 탐색을 용이하게 했습니다.
- **그리드 필터 (Grid Size)**: 화면에 한 번에 보여줄 사진 열의 개수(1, 3, 5, 10)를 실시간으로 전환할 수 있는 직관적인 번호 필터 버튼을 추가했습니다. 모바일 기기의 작은 화면부터 대형 모니터까지 유저가 쾌적하게 앨범을 감상할 수 있게 돕습니다.

### 6.4 프로필 및 인증 테마 (Auth & Profile)
- **프로필/로그아웃 버튼 차별화**: 홈/추억/채팅(Search/Chat) 등 기본 메뉴들과 성격이 다른 점을 시각적으로 알리기 위해, 프로필/로그인 버튼은 둥근 투명 테두리를 주고 백그라운드가 채워지는 일반 버튼이 아닌, 배경은 하얗지만 테두리에 포인트(`border-[#EAE5D9]`)를 주는 디자인으로 차별화했습니다.
- **로그인 팝업 (Auth Modal)**: 페이지 이동 없이 흐름을 이어가기 위해 화면 중앙에 부드럽게 오버레이(blur 바탕)되는 모달 팝업 형태로 제작하여 테라코타(주황/브라운) 포인트 컬러를 동일하게 이어나갔습니다.

### 6.5 용어 변경
- **Search/Chat**: 기존 '챗봇(Chat)'의 역할을 사진 검색(Search) 측면에서도 강조하기 위해 툴팁과 명칭을 `Search/Chat`으로 명확히 하였습니다.
