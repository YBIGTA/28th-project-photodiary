# UI 명세서

## 1. 간단 설명

- 반응형 웹 페이지
 
## 2. 기술 스택

- HTML, CSS, JavaScript
- React.js
- Tailwind CSS

## 3. UI 구현

### 로고
- 왼쪽 위 가장 구석에 로고를 위한 공간 마련

### 메뉴
- 공통 (로고 오른쪽에 [+] 버튼에서 사진 업로드 가능, 앨범/챗봇 VIEW 사이에 스위칭할 수 있는 버튼 두 개를 왼쪽 가장자리에 배치) (사이드바는 따로 제작하지 않는다)
- 앨범 VIEW (데이터베이스에 있는 사진 날짜별 나열)
- 챗봇 VIEW (주 기능, 유저 쿼리에 따른 챗봇 사진 반환)

### 디자인
- 일단은 심플하게 가자. 흰색 및 하늘색 계열의 심플한 디자인, 다크 모드 없음
- 기능이 많지 않으니 현존하는 기능에 집중, 기능만큼이나 전반적으로 심플한 디자인

## 4. UI 세부 사항

### PC 인터페이스

#### 앨범VIEW
- 앨범 VIEW에서도 채팅창과 상호작용 가능
- 앨범 VIEW에서 검색창에 프롬프트 입력하면 채팅창으로 변함, 채팅창이 아래쪽으로 확장되어 챗봇의 출력 볼 수 있음 (채팅창은 전체 UI 세로 크기를 대부분 차지하는 큰 박스, 스크롤 가능)

#### 챗봇VIEW
- 채팅 화면 일부 공간 할당해서 ‘사진 갤러리’ VIEW 제작
    - 챗봇이 반환하는 사진 크게 보여 줌
    - 모든 대답(일반 에이전트의 일상 대화 빼고)은 사진을 동반하고, 사진을 보는 것이 중요하니까 사진을 크게 보여줌
    - 평소에는 숨어 있다가, 사용자가 첫 쿼리 보내고 챗봇이 대답으로 사진 반환할 때 확장
    - 가로로 길게 (챗봇UI 가로 꽉 채워서), 세로로는 전체 화면의 1/2
    - 사이드스크롤로 사진들 탐색 가능 (스냅 스크롤 아님)
    - 최대 10개의 사진 (이거는 바뀔 수 있음)
    - 사진 호버링하면 캡션(키워드 목록) 표시
    - 개별 사진 클릭하면 화면 가득 사진을 띄워주는 라이트박스 기능 
- or 채팅 화면을 세로로 반 갈라 채팅 왼쪽, '사진 갤러리' VIEW를 오른쪽? (둘 다 해보기)
- 채팅창은 가장 일반적인 디자인으로 시작 
    - 오른쪽에 사용자의 질문이 오도록
    - 왼쪽에 챗봇의 대답이 오도록
    
- 사진 분석 및 RAG 검색이 오래 걸릴 수 있으므로, 답변을 생성 중일 때 '생성 중...' 애니메이션을 챗봇 답변 영역에 표시


### 모바일 인터페이스

- Hamburger Menu처럼 버튼 눌러야 메뉴 나오지 않고, (모바일 앱이나 웹사이트처럼) 최하단에 내비게이션 메뉴 (Bottom Navigation Bar)로 앨범 VIEW / 채팅 VIEW 전환 가능
- 아이폰의 홈 바 등과 내비게이션 바가 겹치지 않도록 safe area 여백 설정 (ex. pb-[safe-area])

#### 앨범 VIEW 
- 검색창 위쪽 길게 
- 검색창에 요청 입력하면 챗봇 VIEW로 바로 넘어감

#### 챗봇 VIEW
- 사용자 터치 위치를 고려해, 채팅 화면을 가로로 1:2 위치에 갈라 '사진 갤러리' VIEW는 화면 위쪽에 위치 (세로 1/3), 화면 아래쪽은 채팅 영역 (세로 2/3)
- 키보드가 올라올 공간 또한 고려, 키보드가 올라오면 일시적으로 '사진 갤러리' VIEW가 위로 밀려들어감


## 5. 구현 프롬프팅 과정

2. **모바일 인터페이스, 챗봇 VIEW**:

4. **모바일 인터페이스, 앨범 VIEW**
